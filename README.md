# Classic90s 🍵
 
A cozy, old 90s songs site, just sit with the song for a while. 

**[Live site](https://classic90s.vercel.app)**

## Getting started

```bash
git clone https://github.com/thunderzz12/Classic90s
npm install
npm run dev
```
